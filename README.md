# Lecture-to-Summary — автоматическое создание конспектов лекций

**Fullstack-веб-приложение** для автоматической генерации структурированных конспектов учебных материалов (лекции, статьи, книги) с использованием **GigaChat API**.

---

## Возможности

- Загрузка файлов в форматах **PDF, DOCX, TXT** (drag & drop или кнопка)
- Ручной ввод текста
- Автоматическое выделение ключевых тезисов, терминов и определений
- Генерация конспекта в формате **Markdown** с заголовками, списками и структурой
- Настройка детализации: «Кратко» (до 10% исходного текста) или «Подробно» (до 30%)
- Встроенный **Markdown-редактор** для ручной правки
- Экспорт конспекта в **PDF, DOCX, MD**
- Адаптивный интерфейс (работает на ПК, планшетах, телефонах)
- Тёмная / светлая тема

---

## Технологический стек

### Frontend
| Технология | Назначение |
|------------|------------|
| React 18 + Next.js 14 | UI-библиотека + мета-фреймворк |
| TypeScript | Статическая типизация |
| Ant Design + Tailwind CSS | UI-компоненты + стилизация |
| Axios | HTTP-запросы |
| React-markdown + remark-gfm | Рендеринг Markdown |
| react-simple-typewriter | Анимация «печати» |
| Redux Toolkit | Управление состоянием |

### Backend
| Технология | Назначение |
|------------|------------|
| Adonis.js | Node.js фреймворк (MVC) |
| SQLite3 | Реляционная база данных |
| GigaChat API | NLP-обработка текста |
| REST API | Взаимодействие с frontend |
