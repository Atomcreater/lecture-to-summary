# Lecture-to-Summary — автоматическое создание конспектов лекций

**Fullstack-веб-приложение** для автоматической генерации структурированных конспектов учебных материалов (лекции, статьи, книги) с использованием **GigaChat API**.

---

## Возможности

- Загрузка файлов в форматах **PDF, DOCX, TXT** (drag & drop или кнопка)
- Ручной ввод текста
- Автоматическое выделение ключевых тезисов, терминов и определений
- Генерация конспекта в формате **Markdown** с заголовками, списками и структурой
- Настройка детализации: «Кратко» (до 10% исходного текста) или «Подробно» (до 30%)
- Встроенный **Markdown-редактор** для ручной правки
- Экспорт конспекта в **PDF, DOCX, MD**
- Адаптивный интерфейс (работает на ПК, планшетах, телефонах)
- Тёмная / светлая тема

---

## Технологический стек

### Frontend
| Технология | Назначение |
|------------|------------|
| React 18 + Next.js 14 | UI-библиотека + мета-фреймворк |
| TypeScript | Статическая типизация |
| Ant Design + Tailwind CSS | UI-компоненты + стилизация |
| Axios | HTTP-запросы |
| React-markdown + remark-gfm | Рендеринг Markdown |
| react-simple-typewriter | Анимация «печати» |
| Redux Toolkit | Управление состоянием |

### Backend
| Технология | Назначение |
|------------|------------|
| Adonis.js | Node.js фреймворк (MVC) |
| SQLite3 | Реляционная база данных |
| GigaChat API | NLP-обработка текста |
| REST API | Взаимодействие с frontend |

## 👨‍💻 Мой вклад в проект — Backend Developer

В рамках командной курсовой работы **«Разработка приложения для автоматического создания конспектов лекций»** я отвечал за серверную часть веб-приложения.

**Основной стек:** Node.js, JavaScript, REST API, GigaChat API, Git.

### 🔧 Основные задачи

**1. Разработка серверной логики**
- Разработка backend-части приложения на Node.js.
- Организация взаимодействия между пользовательским интерфейсом и сервером.
- Обработка запросов от frontend-приложения.

**2. Проектирование и реализация REST API**
- Создание API для взаимодействия frontend и backend.
- Реализация обработки запросов на загрузку и обработку учебных материалов.
- Передача результатов обработки в структурированном формате JSON.

**3. Интеграция GigaChat API**
- Подключение внешнего API языковой модели GigaChat.
- Организация передачи текста лекций для автоматического формирования конспектов.
- Обработка ответов языковой модели и передача результатов пользователю.

**4. Обработка данных**
- Реализация серверной логики обработки текстовых материалов.
- Подготовка данных для передачи в языковую модель.
- Обработка результатов генерации конспектов.

**5. Командная разработка**
- Согласование API и форматов данных с frontend-разработчиком.
- Использование Git и GitHub для контроля версий.
- Участие в интеграции и проверке работы компонентов приложения.

### 🎯 Результат работы

В рамках проекта разработана серверная часть приложения, обеспечивающая взаимодействие пользовательского интерфейса с GigaChat API для автоматического формирования структурированных конспектов учебных материалов.

Проект позволил получить практический опыт backend-разработки, проектирования REST API, интеграции внешних сервисов и командной работы.
